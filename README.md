# Nextgen Workforce Premium Website

Static bilingual website concept built for Nextgen Workforce.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to Cloudflare Pages, Netlify, GitHub Pages, or any static host.

## Important before production
- Replace the temporary “N” brand mark with the final client logo.
- Connect forms to the client’s preferred backend/CRM instead of `mailto:`.
- Confirm final service area, legal/privacy text, and social media links.
- Replace or self-host stock photography if desired.
